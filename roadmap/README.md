# ZeroCloud Roadmap (Proposed)

1. **Foundation:** documentation taxonomy, glossary, trust boundaries, ADRs, canonical schemas.
2. **Software prototype:** ZeroSchedule and ZeroDispatch with synthetic fixtures, tests, conflict detection and Metro dashboards.
3. **Communications:** ZeroPBX/ZeroVoice with explicit consent and supported headset integrations.
4. **Estate simulation:** digital twin, synthetic robot fleet, tavern and candlelit-dinner workflow evaluation.
5. **Hardware integration:** capability contracts, supervised clanker prototypes, independently verified safety controls.
6. **Hospitality pilot:** opt-in experience delivery, privacy-preserving metrics, human service fallback.
7. **Research platform:** reproducible datasets, simulations, staged model evaluations and governed deployments.

Each phase requires acceptance criteria, risk review, documentation updates and rollback plan.
