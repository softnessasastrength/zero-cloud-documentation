# Data models

Task: ID, request/correlation IDs, title, resource, start/duration, dependency IDs, status, optional execution timestamps, scope and approval flags. Clanker: identity, role, location, battery, health, charging, firmware, temperature and maintenance ledger. Telemetry: timestamp, type, identifiers, transition, latency and simulated quality marker.

Dashboard v1 contains a name and up to 30 widgets. Zod validates imported JSON including supported sources, integer refresh intervals 1–60, and unique IDs. Tile contains route, size, group, background and metric. Browser persistence is versioned as workspace v1 in zerocloud-playground-v1 IndexedDB. Experience fields are briefing metadata; only assigned staff and arrival influence execution.
