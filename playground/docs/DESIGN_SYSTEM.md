# Metro design system

Open Sans Variable is bundled from its font package with its upstream license. Segoe UI is a system fallback; no Microsoft font or artwork is redistributed. Lucide supplies outline icons.

The interface uses oversized lightweight titles, square saturated tiles, edge-aligned grids, horizontally scrolling pivot navigation, and a persistent contextual simulation bar. Default background #101112; accent #007f87. Tile backgrounds remain independently configurable. Dark and light themes use CSS variables; light mode retains dark hero panels. No glass or rounded cards.

Small tiles occupy one grid unit; medium 2×2; wide 4×2; large 4×4. Phone Start groups are horizontal snap regions with visible adjacent content. Keyboard arrows in the inspector substitute for dragging. Reduced motion disables entrance and tile transitions. Bespoke touch gesture recognition and 3D tile flips remain future work.
