# Accessibility

Semantic navigation, headings, explicit form labels, focus outlines, skip-to-content, status notifications, and native controls support keyboard operation. Tile and widget move buttons provide drag alternatives. Reduced-motion preference disables animation. Responsive layout collapses columns while panorama and navigation remain horizontally scrollable. Charts expose a table of recent observations.

Remaining validation: full screen-reader audit, automated contrast audit across custom accents, browser zoom testing and real-device touch testing. User-selected colors can reduce contrast. Role-based hiding is demonstrated on synthetic calendars and event traces; it is not a substitute for server enforcement.
