# Components

PageTitle provides eyebrow and title hierarchy. Field wraps inputs in accessible labels. Empty describes unavailable data. StatusTag represents engine states. DataWidget samples a named synthetic source at a configured interval; Chart provides a text table alternative. Start and Designer use these same components as an interactive component workbench; a standalone Storybook is not yet included.

Widget sources: fleet availability, pending tasks, injected faults, modeled charging load and battery history. Charts use actual sampled simulation history. Energy is a model, not a meter reading. Refresh intervals measure wall-clock seconds while timestamps are simulation minutes.
