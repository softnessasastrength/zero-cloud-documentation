# ZeroLab / ZeroSim / ZeroValidate v0.1

## Research loop
Production operations -> purpose-limited operational telemetry -> minimization and aggregation -> offline experiment -> simulation -> regression/safety evaluation -> human-reviewed change proposal -> staged rollout with rollback.

## Example: Jakey's Tavern
A table-for-six event records requested time, room readiness, setup duration, staffing allocation, energy use, and exception outcomes. An offline model proposes parallel glassware and furniture preparation. ZeroSim checks resource and collision constraints before any live test.

## Research safeguards
- Guests and household members are not research subjects by default.
- Personal messages, private conversations and identifiable presence traces are excluded without explicit appropriate consent.
- Experimental AI has no direct actuator, purchase, security or safety-controller permissions.
- Datasets have provenance, retention limits, access logs, and deletion procedures.
- Distinguish measured outcomes, simulations, estimates and hypotheses.
- Use holdout tests, regression suites, shadow-mode evaluation and rollback criteria.

## First experiments
Scheduling deadline prediction; multi-clanker dispatch; equipment fault forecasting; venue setup optimization; charging coordination; outage resilience.
